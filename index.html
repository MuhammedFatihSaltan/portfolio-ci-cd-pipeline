Mülakatlara ve Sektöre Yönelik Temel Bilgi Kartları

// CONTINUOUS INTEGRATION & DEPLOYMENT

CI / CD Nedir?

CI (Sürekli Entegrasyon): Geliştiricilerin kodlarını ana depoya her push ettiğinde otomatik olarak test edilmesi ve derlenmesidir.

CD (Sürekli Dağıtım): Testlerden başarıyla geçen kodun, insan müdahalesi olmadan otomatik olarak canlı sunuculara (Örn: AWS S3) aktarılması sürecidir. Hata riskini sıfıra indirir.

// INFRASTRUCTURE AS CODE

IaC Nedir?

Sunucuları, ağları ve veri tabanlarını AWS paneline girip elle (manuel) tıklayarak oluşturmak yerine, **kod yazarak (Terraform, CloudFormation vb.)** otomatik olarak ayağa kaldırma felsefesidir.

Bu sayede altyapı dokümante edilmiş olur, versiyonlanabilir ve tek bir komutla dünyanın başka bir yerindeki veri merkezinde birebir kopyası kurulabilir.

// CLOUD COMPUTING / AWS

Neden AWS Cloud?

AWS, dünyanın en büyük ve güvenilir bulut sağlayıcısıdır. Şirketlere fiziksel sunucu maliyetinden kurtulma imkanı sunar.

S3: Sınırsız dosya depolama alanı sunar, statik web siteleri için mükemmel bir hosting alanıdır.
CloudFront: İçerikleri dünya genelinde önbelleğe alarak (CDN) web sitelerinin milisaniyeler içinde açılmasını sağlar.
